MALWARE TYPE: Banking Trojan / Cryptominer / Dropper Hybrid
RISK LEVEL: CRITICAL (9/10)
THREAT CATEGORY: Financial Fraud, Cryptocurrency Mining, Malware Distribution

This APK masquerades as "Axis Cards" - a legitimate Indian banking application
from Axis Bank. The malware exhibits multiple malicious behaviors including:

  • Cryptocurrency mining using device resources
  • Dropper functionality to install additional malicious payloads
  • Aggressive persistence mechanisms to survive reboots and battery optimization
  • Command & Control (C2) communication via HTTP/HTTPS and Firebase Cloud Messaging
  • Identity deception with ability to change launcher icon to "Play Store"
  • Heavy code obfuscation using Unicode strings and hash-based control flow

The malware connects to infrastructure under the "uasecurity.org" domain for
C2 communication, payload delivery, and mining pool connectivity.
