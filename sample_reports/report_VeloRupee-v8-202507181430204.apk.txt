MALWARE TYPE: Predatory Lending / Financial Fraud Application (Illegal Loan App)
RISK LEVEL: HIGH
THREAT CATEGORY: Financial Fraud, PII Harvesting, Privacy Violation

This APK masquerades as a legitimate loan application ("VeloRupee") targeting
Indian users with predatory lending schemes. The application collects sensitive
personal information including phone numbers, location data, and device
identifiers while connecting to suspicious infrastructure. It exhibits
characteristics consistent with illegal instant loan apps that have been
associated with harassment, blackmail, and financial exploitation schemes
prevalent in India.

KEY FINDINGS:
- Fraudulent financial application impersonating a legitimate lending service
- Communicates with suspicious C2 infrastructure on .top TLD (petga.top)
- Collects sensitive PII (phone numbers, location, device info)
- Uses obfuscated package naming to evade detection
- Weak security with cleartext traffic enabled
- Self-signed certificate with suspicious identifiers (admincynlyi)
- Targets Indian market (INR currency, India-specific infrastructure)

                       MALICIOUS BEHAVIORS
================================================================================

1. FINANCIAL FRAUD OPERATION
----------------------------
The application operates as a predatory lending platform with the following
characteristics:

API Endpoints (via l3/b.java interface):
- POST /Index/ajaxSignIn - User authentication with username/password
- GET  /Index/ajaxLogOut - Session termination
- GET  /Repay/loans - Current loan status retrieval
- POST /Repay/orders - Order history pagination
- POST /Repay/payUrl - Payment URL generation
- POST /Loan/reLoan - Loan re-application
- POST /Feedback/ajaxCreate - Feedback submission with attachments
- POST /Info/ajaxUpload - File/document upload

Loan Data Structures (CurrentOrder.java):
- money, repay_money, serviceFee, commission
- loan_time, repayment_time, default_deadline
- default_loan_interest, default_repay_interest
- hasOverdue (overdue tracking for harassment)

Bill Tracking (Bill.java):
- oid (order ID), money, delay, delay_day
- repay_interest, repayment_time

Currency: Indian Rupee (INR) - Formatted as Rs (see a.java: "Rs" prefix)

2. PERSONAL INFORMATION HARVESTING
----------------------------------
The application collects and transmits:

a) Phone Identity:
   - READ_PHONE_STATE: Device IMEI, IMSI, phone number
   - READ_PHONE_NUMBERS: Direct phone number access
   - User credentials stored in SharedPreferences ("user_info")

b) Location Data:
   - ACCESS_FINE_LOCATION: GPS coordinates
   - ACCESS_COARSE_LOCATION: Cell tower/WiFi location
   - EXIF GPS extraction from uploaded photos

c) Device Information:
   - Network state, WiFi state
   - Device model, Android version
   - Screen orientation locked (portrait mode)

d) User Content:
   - Camera access for document capture
   - Gallery access for image selection
   - Uploaded files sent to C2 server

3. SESSION PERSISTENCE
----------------------
- PHPSESSID cookie tracking via OkHttp CookieJar
- Session validation through /Index/ajaxSignIn endpoint
- Cookie persistence in SharedPreferences
- Session state check via petga.top PHPSESSID presence

4. POTENTIAL DROPPER CAPABILITY
-------------------------------
- REQUEST_INSTALL_PACKAGES permission present
- Could download and install additional malicious APKs
- No active dropper code identified in current version
