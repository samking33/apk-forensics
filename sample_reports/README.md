## Report Format

Each report includes:
- Executive Summary
- APK Metadata (SHA-256, package name, version)
- Permissions Analysis
- Attack Surface Analysis
- Malicious Behaviors
- Network IoCs (URLs, IPs, domains)
- File/Payload IoCs
- Attribution Data
- YARA Detection Rules
- Snort/Suricata IDS Rules
- Remediation Recommendations
